🌟 音乐侧边栏制作完全指南（BGM播放器）

这份指南教你做一个完整的BGM播放器侧边栏。包含歌曲列表、播放控制、进度条、音量调节、播放模式切换、自动切歌联动等所有功能。

---

一、核心组成

部分 内容 说明
CSS样式 触发按钮、播放面板、进度条、控件、歌曲列表 类名加统一前缀（如bgm-）
HTML结构 触发按钮 + 滑出面板 + 歌曲列表 + 控制按钮 面板默认隐藏，点击滑出
JavaScript Audio对象管理、播放/暂停/切歌、进度条更新 Audio对象挂window，函数加前缀

}
}

三、怎么改

要改什么 改哪里
歌曲列表 window.bgmPlaylist 数组里的 url 和 title
面板标题 HTML里 .bgm-panel-title 的文字
触发按钮文字 HTML里 .bgm-trigger 的文字
默认音量 window.bgmAudio.volume = 0.4 改成 0-1 之间
按钮位置 CSS里 .bgm-trigger 的 top 值
面板宽度 CSS里 .bgm-panel 的 width
自动切歌对应关系 stageSongMap 对象，键是阶段名，值是歌曲索引

---

四、注意事项

项 说明
Audio对象全局唯一 必须 window.bgmAudio，避免多实例同时播放
浏览器自动播放限制 首次播放需要用户手势触发，.play() 后加 .catch(function(){})
自动模式下锁曲循环 ended 事件里如果自动播放开，就单曲循环，不跳下一首
实时切歌 通过 setInterval 每3秒读 window.__GC_DATA 判断阶段变化
状态栏必须挂载全局数据 状态栏引擎 renderUI 末尾必须有 window.__GC_DATA = kv
面板关闭清理 点击面板外部时移除 open 类并恢复触发按钮

---

五、常见BUG

问题 原因 修复
点按钮没反应 函数没挂 window window.bgmTogglePanel = function(){}
自动切歌不工作 自动开关关或 __GC_DATA 不存在 检查开关和状态栏引擎
面板打开后立刻关闭 事件冒泡 面板和按钮都加 event.stopPropagation()
播放没声音 浏览器阻止自动播放 第一次播放需要用户点击触发
进度条不走 timeupdate 没触发 检查 bgmAudio 事件绑定
换阶段后还播旧歌 stageSongMap 索引写错 检查键名和索引是否匹配
