🌟 开屏动画详细教程

开屏动画是玩家第一次进入角色卡时展示的全屏覆盖层。包含卡名、主题诗句、卡片简介，配合背景粒子动画。点击任意位置后淡出消失，之后不再自动显示。

---

一、它放在哪里

放在功能栏的一条正则替换里。查找内容可以是任意触发词（如 <SPLASH>），替换为下面的完整代码。

---

(function() {
  var STORAGE_KEY = 'pd_splash_shown';
  var shown = false;
  try { shown = localStorage.getItem(STORAGE_KEY) === '1'; } catch(e) {}

  var overlay = document.getElementById('pd-overlay');

  if (!shown && overlay) {
    overlay.style.display = 'flex';
    document.body.classList.add('pd-body-hidden');
    try { localStorage.setItem(STORAGE_KEY, '1'); } catch(e) {}
  } else if (overlay) {
    overlay.style.display = 'none';

  if (overlay) {
    overlay.addEventListener('click', function(e) {
      if (e.target === overlay) {
        overlay.classList.add('fade-out');
        document.body.classList.remove('pd-body-hidden');

})();

---

三、怎么改

要改什么 改哪里
开屏文字 找到 .pd-block-* 里的 .pd-line，改文字
背景颜色 改 .pd-overlay 的 background
粒子颜色 改 .pd-particle 的 background 和 .pd-float 里的颜色
粒子数量 复制或删除 .pd-particle 的 <div>
字体 改 .pd-overlay 的 font-family
动画速度 改 animation-delay 的值

---

四、常见问题

问题 修复
刷新后又出现 检查 localStorage key 是否被覆盖
底部文字不居中 已用 left:0;right:0;text-align:center，不要改
开屏期间输入框还能点 确认 pd-body-hidden 类已添加
粒子卡顿 减少粒子数量或在移动端降级
