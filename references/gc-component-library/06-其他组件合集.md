组件四：状态图鉴侧边栏

是什么

自动收录状态栏中出现的角色数据，用六维雷达图展示。玩家可选2-4人进行对比。页面加载时自动清空旧数据，只保留当前对话的角色。

核心逻辑

```js
// 页面加载时清空旧数据
try{ localStorage.removeItem('xx2_roster'); localStorage.removeItem('xx2_meta'); }catch(e){}

// 监听状态栏数据更新
window.addEventListener('gc-dataupdate', function(e) {
  var kv = e.detail && e.detail.data;
  if(!kv) return;
  var curRound = parseInt(kv['轮次']) || 0;
  var list = load();
  // 只保留最近4轮出现的角色
  list = list.filter(function(it) { return curRound - (it.lastRound||curRound) <= 4; });
  // 收录玩家
  upsert(list, kv, '玩家', curRound);
  // 收录NPC（只收正典角色）
  for(var i=1;i<=4;i++){
    var nm = kv['NPC'+i+'姓名'];
    if(nm && isCanonical(nm)) upsert(list, kv, 'NPC'+i, curRound);
  }
  save(list);
});
```

完整代码参考之前的状态图鉴侧边栏。核心注意点是：页面加载清空旧数据，防止跨对话残留。

组件六：小游戏侧边栏

是什么

内嵌Canvas小游戏的侧边栏。玩家点击侧边栏按钮，弹出游戏面板。

核心注意事项

项 说明
Canvas在display:none时被清空 打开面板时强制重置 canvas.width 触发重建
游戏循环 用 requestAnimationFrame，切换标签时暂停
面板阻止冒泡 面板和Canvas都要加 event.stopPropagation()
按钮层级 触发按钮 z-index: 9998，遮罩层 100000

关键修复代码：

```js
window.gameOpen = function() {
  overlay.classList.add('open');
  setTimeout(function() {
    canvas.width = 320;
    canvas.height = 440;
    ctx = canvas.getContext('2d');
    draw();
  }, 100);
};
```

合集通用注意事项

序号 注意 说明
1 依赖状态栏全局数据 所有实时组件都需要 window.__GC_DATA
2 状态栏引擎必须挂载 renderUI 末尾 window.__GC_DATA=kv
3 浏览器自动播放限制 音频播放需用户手势
4 Canvas重建 display:none 后需重置宽高
5 localStorage操作加try-catch 隐私模式可能失败
6 类名统一前缀 防冲突
7 函数挂载window onclick 调用的都要挂
8 所有可点击元素阻止冒泡 event.stopPropagation()
9 移动端适配 面板宽度 ≤98%，按钮位置调整
10 层级规范 按钮9998→遮罩层100000→面板100001→开屏999999
