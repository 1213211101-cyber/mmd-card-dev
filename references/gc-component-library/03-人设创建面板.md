🌟 人设创建面板完全指南（超详细版）

一、什么是人设创建面板

人设创建面板是放在角色卡第一句话里的交互表单。玩家进卡就能看到，填写自己的角色设定——姓名、性别、年龄、身份、性格等。填完后点确认，表单内容会追加到输入框，AI根据这些设定开始剧情。

它和侧边栏捏人的本质区别：

 人设创建面板 侧边栏捏人
位置 第一句话里，聊天区顶部 页面侧边，固定按钮呼出
触发时机 进卡就看到，通常只填一次 任何时候都可以打开
用途 为"这张卡的剧情"设定玩家角色 为"当前场景"临时生成一个NPC
关闭后 面板消失，设定已发送，不会再出现 随时可以再打开，再创建
代码部署 三段正则拆分，放聊天区 一段正则，放聊天区或功能栏
典型场景 进卡先填"你是谁"，然后AI开始故事 玩到一半想加个新NPC，打开侧边栏捏一个

本质区别：人设创建是"初始化"，侧边栏捏人是"随时追加"。

---

二、三段正则拆分

因为人设创建面板内容通常超过20000字符，必须拆成三段：

正则 匹配 替换内容 放在哪
正则1 <JH_1> 样式表 + HTML前半（基础信息区） 聊天区
正则2 <JH_2> HTML后半（映射预览 + 确认按钮） 聊天区
正则3 <JH_3> <script> 完整JS逻辑 聊天区

关键规则：分段时HTML标签必须跨段闭合。 正则1结束时如果有未闭合的 <div>，正则2开头必须继续写。正则3负责关闭所有未闭合的标签。

验证方法： 数三段代码中 <div> 和 </div> 的数量是否匹配。正则1开了几个未闭合的 <div>，正则2就要接几个，正则3负责全部关掉。

正则3：完整JS逻辑（逐行解释）

```html
<script>
(function() {
  // ====== 防重复初始化 ======
  if (window.__jhInstalled) return;
  window.__jhInstalled = true;

  // ====== 状态管理 ======
  var state = {
    gender: '男',           // 默认性别
    identity: '',           // 身份
    personality: []         // 性格数组（多选）
  };

  // ====== 性别选择（单选） ======
  window.jhSetGender = function(g, ev) {
    // ★ ev 是事件对象，通过 onclick="jhSetGender('男',event)" 传入
    if (!ev) ev = window.event;  // 兼容旧浏览器

    state.gender = g;  // 更新状态

    // 清除所有标签的选中样式
    var tags = document.querySelectorAll('#jh-gender-tags .jh-tag');
    for (var i = 0; i < tags.length; i++) {
      tags[i].classList.remove('selected');
    }

    // 给当前点击的标签加上选中样式
    ev.currentTarget.classList.add('selected');

    jhUpdatePreview();  // 更新映射预览
  };

  // ====== 身份选择（单选 + 自定义联动） ======
  window.jhSelectIdentity = function(val, ev) {
    if (!ev) ev = window.event;

    state.identity = val;  // 更新状态

    // 清除所有标签的选中样式
    var tags = document.querySelectorAll('#jh-identity-tags .jh-tag');
    for (var i = 0; i < tags.length; i++) {
      tags[i].classList.remove('selected');
    }
    ev.currentTarget.classList.add('selected');

    // ★ 如果选了"自定义"，显示自定义输入框；否则隐藏
    var custom = document.getElementById('jh-identity-custom');
    if (custom) {
      custom.style.display = (val === '自定义') ? 'block' : 'none';
    }

    jhUpdatePreview();
  };

  // ====== 性格切换（多选，最多3个） ======
  window.jhTogglePersonality = function(val, ev) {
    // ★ 这个函数名是 Toggle（切换），不是 Select（单选）
    if (!ev) ev = window.event;
    var el = ev.currentTarget;  // 被点击的标签元素

    var idx = state.personality.indexOf(val);  // 查找这个值是否已在数组中

    if (idx >= 0) {
      // 已选中 → 取消选中
      state.personality.splice(idx, 1);  // 从数组中移除
      el.classList.remove('selected');   // 去掉高亮
    } else {
      // 未选中 → 检查是否达到上限（3个）
      if (state.personality.length < 3) {
        state.personality.push(val);     // 加入数组
        el.classList.add('selected');    // 加上高亮
      }
      // 如果达到上限，什么都不做（不选中，也不提示）
    }

    jhUpdatePreview();
  };

  // ====== 更新映射预览 ======
  window.jhUpdatePreview = function() {
    var p = document.getElementById('jh-preview-content');
    if (!p) return;

    // 读取所有输入框的值
    var name = document.getElementById('jh-name').value.trim() || '未填写';
    var age = document.getElementById('jh-age').value.trim() || '未填';
    var customId = document.getElementById('jh-identity-custom').value.trim();
    var finalIdentity = state.identity === '自定义'
      ? (customId || '未指定')
      : (state.identity || '未选择');

    // 读取自定义性格输入
    var customPer = document.getElementById('jh-personality-custom').value.trim();
    var finalPersonality = state.personality.slice();  // 复制数组，不修改原数组

    // 把自定义性格合并进去
    if (customPer) {
      var extras = customPer.split(/[,，]/);  // 支持中英文逗号分隔
      for (var i = 0; i < extras.length; i++) {
        var s = extras[i].trim();
        // 不重复、不超上限才加入
        if (s && finalPersonality.indexOf(s) < 0 && finalPersonality.length < 3) {
          finalPersonality.push(s);
        }
      }
    }

    // 拼接预览文本
    var text = '【角色设定】\n';
    text += '姓名：' + name + '\n';
    text += '性别：' + state.gender + '\n';
    text += '年龄：' + age + '\n';
    text += '身份：' + finalIdentity + '\n';
    text += '性格：' + (finalPersonality.length ? finalPersonality.join('、') : '未选择');

    p.textContent = text;  // ★ 用 textContent，不用 innerHTML
  };

  // ====== 确认创建 ======
  window.jhConfirm = function() {
    // ★ 验证必填项
    var name = document.getElementById('jh-name').value.trim();
    if (!name) {
      alert('请先填写姓名');
      return;
    }

    // 获取预览文本
    var t = document.getElementById('jh-preview-content').textContent.trim();

    // ★ 找到输入框（多个备选，防止平台换类名）
    var ta = document.querySelector('.chatMsgTextarea textarea') ||
             document.querySelector('.chat-input-scope textarea') ||
             document.querySelector('.chat-bottom textarea') ||
             document.querySelector('textarea');

    if (!ta) {
      alert('未找到输入框，请刷新页面重试');
      return;
    }

    ta.value = t;
    // ★ 必须触发 input 事件，否则平台检测不到值变化
    ta.dispatchEvent(new Event('input', { bubbles: true }));
    ta.focus();  // 聚焦到输入框，方便玩家看到内容
  };

  // ====== 初始渲染 ======
  jhUpdatePreview();

})();
</script>
```

四、常见BUG与修复（重点！）

❌ BUG 1：点击标签有高亮，但映射预览没更新

现象： 标签颜色变了（选中/取消），但映射预览里的文字没变。

原因： onclick 里没传 event 参数。

错误写法：

```html
<div class="jh-tag" onclick="jhTogglePersonality('沉稳')">沉稳</div>
```

正确写法：

```html
<div class="jh-tag" onclick="jhTogglePersonality('沉稳',event)">沉稳</div>
```

为什么？ 函数内部通过 ev.currentTarget 获取被点击的元素来切换 selected 类。不传 event，ev.currentTarget 为 null，高亮切不了，预览也不更新。

---

❌ BUG 2：确认按钮点了完全没反应

现象： 点击"确定设定"后，什么也没发生，没有文字追加到输入框。

常见原因有三个：

原因 检查方法 修复
函数没挂到 window 控制台输入 window.jhConfirm 看是不是 undefined 改为 window.jhConfirm = function(){}
必填验证拦截了 看有没有弹窗提示"请先填写姓名" 填写姓名后再试
dispatchEvent 没触发 检查代码里有没有 ta.dispatchEvent(...) 必须加这一行

---

❌ BUG 3：追加到输入框后，发送出去的是空的

现象： 文字确实出现在输入框里了，但点击发送后，AI收到的消息是空的。

原因： 只设置了 ta.value，但没有触发 input 事件。MMD平台使用React/Vue等框架，这些框架通过监听 input 事件来检测输入框的值变化。你改了 value 但不触发事件，框架不知道值变了。

修复： 必须加这行：

```js
ta.dispatchEvent(new Event('input', { bubbles: true }));
```

---

❌ BUG 4：自定义输入框的内容没反映到预览

现象： 在"自定义身份"或"自定义性格"里打字，映射预览不更新。

原因： 自定义输入框的 oninput 没绑定，或者 jhUpdatePreview 里没读取它的值。

检查两个地方：

1. 输入框是否有 oninput="jhUpdatePreview()"
2. jhUpdatePreview 里是否有读取 getElementById('jh-identity-custom').value

---

❌ BUG 5：面板点击触发聊天气泡编辑

现象： 在面板上点任何地方，都会弹出平台的聊天气泡编辑框。

原因： 面板容器没有阻止事件冒泡。

修复： 面板最外层必须加：

```html
<div class="jh-panel" onclick="event.stopPropagation()">
```

---

❌ BUG 6：分段时HTML标签闭合出错

现象： 状态栏完全崩溃，或者只显示了一半。

原因： 正则1和正则2之间的HTML标签没有正确闭合。

检查方法： 数一下正则1和正则2里 <div> 和 </div> 的数量是否匹配。正则1结束时如果有3个未闭合的 <div>，正则2开头必须还有3个 <div> 等着闭合。

---

❌ BUG 7：性格标签选了第4个没有提示

现象： 已经选了3个性格，点第4个时没有任何反应，也没有提示。

原因： 代码里只做了静默限制（if (state.personality.length < 3)），没有给用户任何反馈。

修复（可选）： 在达到上限时加一个提示：

```js
} else {
  // 可以加一个轻微闪烁提示
  el.style.animation = 'none';
  el.offsetHeight;  // 触发重排
  el.style.animation = 'shake 0.3s ease';
}
```

```js
  var tags = document.querySelectorAll('#jh-job-tags .jh-tag');
  for (var i = 0; i < tags.length; i++) {
    tags[i].classList.remove('selected');

  ev.currentTarget.classList.add('selected');
  var custom = document.getElementById('jh-job-custom');
  if (custom) custom.style.display = (val === '自定义') ? 'block' : 'none';
  jhUpdatePreview();
};
```

七、快速检查清单

部署前逐项检查：

1. □ 面板最外层是否加了 onclick="event.stopPropagation()"
2. □ 所有标签的 onclick 是否都传了 event 参数
3. □ 所有处理函数是否挂载到 window（window.函数名 = function(){}）
4. □ 确认按钮是否触发了 dispatchEvent(new Event('input', {bubbles: true}))
5. □ 正则1和正则2之间的HTML标签是否跨段闭合
6. □ 多选标签是否有数量上限限制
7. □ 自定义输入框是否在选"自定义"时显示、选其他时隐藏
8. □ 映射预览的 jhUpdatePreview 是否读取了所有输入框的值
9. □ 确认按钮是否有必填验证（至少验证姓名）
10. □ 是否有移动端 @media 适配
11. □ 三段正则的顺序是否正确（正则1→正则2→正则3）
12. □ 类名是否全部使用 jh- 前缀
