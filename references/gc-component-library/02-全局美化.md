🌟 全局美化完全指南（超详细版）

这份指南教你从零开始做一个完整的、带悬浮窗切换功能的全局美化。包含日夜双主题、字体切换、拖拽移动、偏好记忆等所有功能。即使你没有任何编程基础，也能照着做出来。

---

一、全局美化是什么

全局美化是一段CSS代码，用来改变聊天界面的所有视觉元素。包括：

· 聊天背景：整个页面的底色
· AI气泡：AI回复的对话框（背景色、边框、文字颜色）
· 用户气泡：你自己发送的消息框
· 输入框：底部打字的地方
· 发送按钮：发送消息的按钮
· 顶部导航栏：有返回、名字、刷新的那条
· 模型切换：选择AI模型的按钮和弹窗
· 滚动条：页面右侧的滚动条
· 指令条：快捷指令按钮

配合JS逻辑，还可以实现：日夜双主题切换、字体美化开关、悬浮球拖拽移动、所有偏好自动保存（刷新后还在）。

---

二、核心概念：CSS优先级和!important

在学代码之前，先理解一个最重要的概念：为什么需要!important？

MMD平台有自己的默认样式。比如AI气泡，平台默认是白底黑字。你写了一段CSS想让气泡变成黑底白字，但平台的默认样式可能比你写的优先级更高，你的代码就失效了。

!important就是强制覆盖。 加了!important的样式，优先级最高，平台的默认样式盖不住你。

```css
/* 没有 !important → 可能被平台覆盖，不生效 */
.chat .item .touch-scope .content.left {
  background: #2a2724;
}

/* 有 !important → 强制覆盖，一定生效 */
.chat .item .touch-scope .content.left {
  background: #2a2724 !important;
}
```

规则：所有颜色、背景、边框、圆角、阴影都要加!important。 布局和尺寸尽量不加。

(function(){
  if(window.__mfInstalled) return;
  window.__mfInstalled = true;

  // ====== 拖拽逻辑 ======
  var dock = document.getElementById('mf-switch-dock');
  var handle = document.getElementById('mf-drag-handle');
  var isDragging = false, startX, startY, startLeft, startTop, hasMoved = false;

  function onStart(e) {
    if (e.target.closest('#mf-panel')) return;
    e.preventDefault();
    isDragging = true; hasMoved = false;
    var p = e.touches ? e.touches[0] : e;
    startX = p.clientX; startY = p.clientY;
    var r = dock.getBoundingClientRect();
    startLeft = r.left; startTop = r.top;
    dock.style.transition = 'none';
  }

  function onMove(e) {
    if (!isDragging) return;
    var p = e.touches ? e.touches[0] : e;
    if (Math.abs(p.clientX - startX) > 3 || Math.abs(p.clientY - startY) > 3) hasMoved = true;
    if (hasMoved) {
      var nl = Math.max(0, Math.min(window.innerWidth - dock.offsetWidth, startLeft + p.clientX - startX));
      var nt = Math.max(0, Math.min(window.innerHeight - dock.offsetHeight, startTop + p.clientY - startY));
      dock.style.left = nl + 'px'; dock.style.top = nt + 'px';
      dock.style.right = 'auto'; dock.style.transform = 'none';
    }
  }

  function onEnd(e) {
    if (!isDragging) return;
    isDragging = false; dock.style.transition = '';
    if (!hasMoved) { document.getElementById('mf-panel').classList.toggle('open'); }
  }

  handle.addEventListener('mousedown', onStart);
  handle.addEventListener('touchstart', onStart, {passive: false});
  document.addEventListener('mousemove', onMove);
  document.addEventListener('touchmove', onMove, {passive: false});
  document.addEventListener('mouseup', onEnd);
  document.addEventListener('touchend', onEnd);

  // ====== 美化/字体切换 ======
  var themeEnabled = true;
  var fontEnabled = true;
  try {
    var saved = localStorage.getItem('mf_settings');
    if(saved){ var s = JSON.parse(saved); themeEnabled = s.theme !== false; fontEnabled = s.font !== false; }
  } catch(e){}

  function saveSettings(){
    try { localStorage.setItem('mf_settings', JSON.stringify({theme: themeEnabled, font: fontEnabled})); } catch(e){}
  }

  function applyTheme(){
    var el = document.getElementById('gc-theme-style');
    if (el) el.disabled = !themeEnabled;
    document.getElementById('mf-toggle-theme').classList.toggle('active', themeEnabled);
    saveSettings();
  }

  function applyFont(){
    var root = document.documentElement;
    if (fontEnabled) {
      root.style.setProperty('--font-body', "'STXingkai','华文行楷','KaiTi','楷体','Hiragino Sans',sans-serif");
      root.style.setProperty('--font-tilt', 'italic');
    } else {
      root.style.setProperty('--font-body', "'Hiragino Sans','Yu Gothic','Noto Sans SC',sans-serif");
      root.style.setProperty('--font-tilt', 'normal');
    }
    document.getElementById('mf-toggle-font').classList.toggle('active', fontEnabled);
    saveSettings();
  }

  window.mfToggleTheme = function(){ themeEnabled = !themeEnabled; applyTheme(); };
  window.mfToggleFont = function(){ fontEnabled = !fontEnabled; applyFont(); };

  applyTheme();
  applyFont();

  document.addEventListener('click', function(e){
    if(!e.target.closest('#mf-panel') && !e.target.closest('#mf-switch-dock')){
      document.getElementById('mf-panel').classList.remove('open');
    }
  });
})();
</script>

五、悬浮球拖拽原理（重要！）

这是最容易出bug的部分。问题在于：拖拽结束后的mouseup和click是两个独立事件。如果你在拖拽结束后重置了移动标志，点击事件就会误判。

正确做法：

```
拖拽开始 → hasMoved = false（清零）
拖拽移动 → hasMoved = true（移动了就标上）
拖拽结束 → 不重置 hasMoved！！！
click事件 → 读hasMoved：true就跳过，false就执行点击
下次拖拽开始 → hasMoved = false（清零）
```

关键代码：

```js
function onStart(e) {
  hasMoved = false;  // ← 每次新拖拽清零
}

function onMove(e) {
  if (移动超过3px) hasMoved = true;  // ← 移动了就标上
}

function onEnd(e) {
  // ← 不重置！留给 click 读
  if (!hasMoved) { /* 这是点击，不是拖拽 */ }
}
```

六、常见错误与修复

❌ 错误1：大块纯色背景遮挡整个聊天区

原因： 用了 body { background: xxx } 或 * { background: xxx }。

修复： 改用 .chat { background: xxx !important; }。body标签不在可修改范围内，*通配符会污染所有元素。

❌ 错误2：顶部导航栏图标和头像一起变色

原因： 用了 .topTabbar img { filter: xxx } 这种太宽的选择器。

修复： 只对图标容器加滤镜，排除头像容器：

```css
.topTabbar [class*="back"] img, .topTabbar [class*="icon"] img { filter: xxx !important; }
.topTabbar [class*="avatar"] img, .topTabbar [class*="head"] img { filter: none !important; }
```

❌ 错误3：字体倾斜把整个气泡框拧歪了

原因： 用了 transform: rotate(0.5deg) 旋转整个容器。

修复： 改用 font-style: italic 只倾斜文字本身，不碰容器。

❌ 错误4：美化开关点了没反应

原因： 样式节点没有唯一ID，或者函数没挂到window上。

修复：

1. 样式节点必须有 id="gc-theme-style"（或其他唯一ID）
2. 开关函数必须挂载：window.mfToggleTheme = function(){...}
3. 通过ID控制：document.getElementById('gc-theme-style').disabled = true/false

❌ 错误5：选择器太短匹配不到

错误写法： .content.left、.chat-bottom

正确写法： .chat .item .touch-scope .content.left、.chat .chat-bottom

平台DOM结构很深，必须写完整路径。

❌ 错误6：颜色没加!important被平台覆盖

所有颜色、背景、边框、圆角、阴影都要加!important。布局和尺寸尽量不加。
