# 轻量选项栏/配角状态栏协议（旧页正则派成品规范）

来源：社区分享（作者"练瑜伽的鲨鱼"开源方案 + 生成规则文档），成品样本见 `assets\community-samples\鲨鱼卡-角色卡正则数据.json`。适合不想上同层全屏层、只要"状态栏 + 可点选项"的卡——全部靠 AI 文本输出 + 正则替换渲染，无自建层。

## 一、AI 输出协议（写进人设/规则给 AI 遵守）

### 选项栏（必须 exactly 三个选项）

```
【选项开始】
选项内容|选项内容|选项内容
【选项结束】
```

- 标识符必须用中文全角方括号【】；三选项用竖线 `|` 分隔，内容里禁止再出现 `|`
- 整个列表写在一行内，由【选项开始】【选项结束】包裹
- 三个选项以用户视角、配合当前情境和故事基调生成，引导下一步行动
- **选项栏必须生成在【配角状态栏】之后**

### 配角状态栏（单行，圆圈数字①~⑥为固定分隔符）

```
【配角状态栏开始】时间戳角色名①境界②外貌③衣装④当前状态⑤内心想法⑥当前事由【配角状态栏结束】
```

- 时间戳：13 位 Unix 毫秒时间戳，纯数字，每次回复必须不同（唯一标识用）
- ①境界 ②外貌 ③衣装 ④当前外在姿势状态 ⑤内心想法（用角色自己的口吻） ⑥当前事由（约 50 字）
- ①②③④⑤⑥ 是固定分隔符，不可替换；内容写在同一行或相邻行，不加额外标签
- 多位女主角时每人都要生成一条；角色立绘从【角色图鉴】提取对应图片

## 二、正则实现（从鲨鱼卡样本提炼，可直接抄）

### 状态栏渲染

```
findRegex: /[【\[]配角状态栏开始[】\]]\s*(\d+)\s*([\s\S]*?)\s*[【\[]配角状态栏结束[】\]]/s
```

捕获组 1=时间戳，组 2=角色名+①~⑥内容，replaceString 里按 ① 切分渲染成卡片（含立绘、六字段排版）。

### 选项栏渲染

```
findRegex: /【选项开始】\s*(.*?)\s*\|\s*(.*?)\s*\|\s*(.*?)\s*【选项结束】/s
```

三个捕获组各渲染成一个可点按钮，点击直发选项文本（防连点）。

### 角色图鉴

纯文本标记替换：`【角色图鉴】` `【角色图鉴1】` `【角色图鉴2】` `【角色图鉴3】` ——每个标记的 replaceString 放对应角色的立绘图床地址 HTML，状态栏渲染时引用。

## 三、鲨鱼卡样本里的四个附加功能（js/css 钩子）

statusbar 字段排布（≤200 字预算内的紧凑写法）：

```
<js1><js2><js3><css1><css2><css3><css4>
/【选项开始】.../s（选项栏正则本体也塞在 statusbar 里）
【游玩助手】×4 【角色图鉴】×4（标记占位）
```

- `<js1>` 切换日夜美化按钮功能代码
- `<js2>` 安全修复双左引号代码（平台文本里的 `“` 成对修复）
- `<js3>` 角色独立微调面板功能代码（玩家可按角色微调样式）
- `<css1>` 全局美化共通 CSS / `<css2>` 日间配色变量 / `<css3>` 夜间配色变量 / `<css4>` 切换按钮+微调面板 CSS

日夜双版的做法：配色全部走 CSS 变量，js1 只切换容器上的主题 class，两套变量块各自独立——比黑洞猫 8.30.4 的单版改色更容易维护，做日夜切换的卡优先抄这套。

## 四、与同层全屏卡的分工

- 本协议：无自建层、零轮询零巡检，AI 输出什么正则渲什么；适合"状态栏 + 选项 + 美化"就够的卡
- 同层全屏卡（见 same-layer-card.md）：需要开屏/捏人/多页/复杂存档时才上
- 两者可混用：同层卡里也可以让 AI 输出【选项开始】块，由层内脚本解析渲染成行动坞按钮
